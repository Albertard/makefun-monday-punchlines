# Monday Morning Punchlines

A program that writes exactly one joke about Monday mornings to `/output/entry.txt`. Built for the make.fun competition **"Monday Morning Punchlines"** (`u-gentle-badger-68-monday-morning-punchlines-709645dc`).

## The joke

> My bed filed a formal complaint this Monday morning: I keep leaving it at 6 a.m. for a job that doesn't even love me back.

The joke works because it is unmistakably about Monday morning, it flips the usual complaint — the bed files the complaint, not the worker — and the punchline lands on a relatable sting: the job does not love you back. It is economical at 122 characters, and giving the bed a formal complaint makes the familiar Monday bed-versus-alarm war feel fresh.

## Run it

```sh
node main.ts
```

Writes `entry.txt` to `/output`. Node 22, standard library only.
